# Security Policy

## Security at Material

Security is an important consideration in the development of Material. We aim to protect users, project contributors, and application data through responsible development and continuous improvement.

## Supported Versions

Security updates are primarily focused on the latest version of the project.

| Version | Security Support |
|---|---|
| Latest | Supported |
| Older versions | Not guaranteed |

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

**Please do not disclose security vulnerabilities publicly through GitHub Issues.**

Instead, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

When reporting a vulnerability, include:

- A clear description of the issue.
- Steps to reproduce the vulnerability.
- The affected component or file.
- Potential security impact.
- Screenshots or proof of concept, if safe to share.

Do not include real passwords, API keys, tokens, or other sensitive information.

## Security Response

The project maintainer will review submitted reports and may:

1. Investigate and validate the reported issue.
2. Assess its potential impact.
3. Develop and test an appropriate fix.
4. Communicate relevant updates.
5. Publish a security fix when appropriate.

Response and resolution times depend on the severity and complexity of the issue.

## Security Best Practices

Contributors should:

- Never commit API keys, passwords, or private credentials.
- Store secrets in environment variables.
- Validate and sanitize user inputs.
- Keep project dependencies updated.
- Follow secure authentication and authorization practices.
- Avoid exposing sensitive user or application data.

## Responsible Disclosure

We appreciate security researchers and contributors who help make Material safer.

Please allow maintainers reasonable time to investigate and address reported vulnerabilities before publicly disclosing them.

**Thank you for helping keep Material secure.**
